# 아이디어 보조 교수님 시연용 앱

API 서버, REST/OpenAPI 계약, 데이터베이스 없이 동작하는 브라우저 앱입니다. React·Vite로 화면을 실행하고 `localStorage`에 단어·폴더·아이디어를 저장합니다. 교수님 앞에서 사용할 화면을 실제로 구현했습니다.

## 실행

현재 PC에서는 의존성이 설치되어 있습니다. `start-demo.cmd`를 더블클릭하거나 아래 명령을 실행하세요.

```powershell
pnpm.cmd dev
```

[시연 앱 열기](http://127.0.0.1:5180/)

표시된 주소를 Chrome·Edge 또는 Codex 브라우저에서 여세요. 실행 창은 시연 동안 유지하고 끝나면 Ctrl+C로 종료합니다. Vite는 화면 파일을 읽는 개발용 실행 도구입니다. 카테고리·생성·저장용 API 서버는 실행하지 않습니다.

다른 PC에서 처음 실행한다면 Node.js 22.12 이상과 pnpm을 준비한 뒤 `pnpm.cmd install`, `pnpm.cmd dev`를 실행합니다.

## 3분 시연 순서

1. 홈에서 `음식 개발` → `선택하고 시작하기`.
2. 가운데 단어를 고정 → `다시 뽑기`. 고정된 위치와 단어가 유지되는지 확인.
3. `이 조합으로 창조하기` → 제목·설명·실행 단계 확인.
4. `더 현실적으로` → 내용 변화 확인. `이전 버전으로 되돌리기`도 가능.
5. `한 걸음 더 구체화하기` → 타깃·문제·핵심 기능·첫 프로토타입 확인.
6. 저장 버튼 → 이름 입력 → 폴더 선택 또는 새 폴더 생성 → `저장하기`.
7. `보관함에서 확인하기` → 저장한 카드 열기.
8. 새로고침 후 보관함 탭 → 저장 내용이 남아 있는지 확인.
9. 가운데 `+` → 카테고리 선택 없이 무작위 조합으로 즉시 생성.

`아이디어 참조`는 이번 앱에 존재하지 않습니다. 탭바는 홈 / + / 보관함입니다.

## 생성 방식 구분

### 간편 시연

기본 모드입니다. 카테고리별 단어와 직접 구현한 규칙으로 생성·발전·구체화를 수행합니다. 실제 AI 모델 추론이 아닙니다. 화면과 저장 카드에도 `간편 시연 · 규칙 기반 결과`로 표시합니다. 인터넷이나 GPU 없이 기본 흐름을 확인할 수 있습니다.

### 브라우저에서 실제 AI 실행

현재 실제 AI 모드는 **실험 기능**입니다. 이 PC에서 모델 다운로드와 생성·발전 추론 응답을 확인했습니다. 그러나 0.5B 모델의 결과는 반복되거나 세 단어를 의미 있게 연결하지 못하는 경우가 있었고, 구체화는 필드 검증에 실패했습니다. 높은 품질의 AI 결과를 교수님 앞에서 안정적으로 보여줄 수 있다고 보장할 수 없습니다. 기본 간편 시연과 실제 AI 기능을 구분해서 설명하세요.

상단 `간편 시연` → `AI 모델 준비하기`를 누르면 WebLLM이 Qwen2.5-0.5B-Instruct 모델을 내려받아 WebGPU로 브라우저 안에서 추론합니다. 클라우드 API 키·API 서버가 필요 없습니다.

- 첫 사용은 수백 MB 모델 다운로드를 위해 인터넷이 필요합니다.
- WebGPU 지원 GPU와 브라우저가 필요합니다. 호환 여부는 설정 화면에 표시합니다.
- 생성·방향별 발전·구체화 모두 실제 모델로 요청합니다.
- AI 요청 실패 시 오류를 표시합니다. 규칙 결과로 몰래 대체하지 않습니다.
- 반복된 실행 단계와 내용 부족은 오류로 표시합니다.
- 작은 모델의 한국어와 추론 품질은 제한적이며, 긴 응답은 느릴 수 있습니다. 5초 응답을 보장하지 않습니다.
- 발표 전에 모델 준비와 실제 생성 결과를 미리 확인하세요.
- 페이지를 새로고침하면 모델은 메모리에서 해제됩니다. 다운로드 캐시가 남으면 다시 준비할 때 재사용합니다.

구현 근거: [WebLLM 공식 사용법](https://webllm.mlc.ai/docs/user/basic_usage.html).

## 저장 주의사항

저장은 같은 PC·같은 브라우저·같은 주소의 `localStorage`에 남습니다. 서버로 전송되지 않습니다. 브라우저 데이터 삭제나 다른 브라우저 사용 시 보관함이 달라집니다. 보관함의 `백업`으로 JSON을 내려받고 `가져오기`로 기존 자료에 더할 수 있습니다. 같은 아이디어를 다시 저장하면 중복 없이 갱신합니다.

## 변경된 기술 구성

| 역할 | 구현 |
|---|---|
| UI | React + lucide-react + CSS |
| 화면 상태 | React `useState` |
| 단어 조합 | JavaScript 역할별 추출 함수 |
| 생성·발전 | 규칙 엔진 또는 브라우저 WebLLM |
| 보관함 | `localStorage` |
| 실행 | Vite |
| 검증 | Node.js 내장 테스트 + 브라우저 실제 조작 |

로컬 작업공간의 이전 `server/`, `data/`, `src/main.jsx`는 이번 앱에서 사용하지 않으며 공유 저장소에도 포함하지 않습니다. 현재 진입점은 `src/demo-main.jsx`입니다. API·DB 관련 패키지와 실행 스크립트는 제거했습니다.

공유받은 PC에서는 저장소를 clone한 뒤 `pnpm.cmd install`, `pnpm.cmd dev`를 실행하세요. 각 PC의 보관함은 독립적으로 저장됩니다. 다른 PC에 아이디어를 옮기려면 JSON 백업을 사용하세요.

## 파일 구성

- `src/demo-main.jsx`: 홈·생성·발전·구체화·저장·보관함
- `src/demo.css`: 반응형 UI와 3탭
- `src/demo/data.js`: 카테고리·단어·조건
- `src/demo/domain.js`: 단어 추출과 규칙 기반 생성
- `src/demo/ai.js`, `ai-worker.js`: 실제 브라우저 모델 추론
- `src/demo/storage.js`: 저장·복원·백업 검증
- `tests/demo.test.js`: 고정·중복·발전·영속성·실패 검증

```powershell
pnpm.cmd test
pnpm.cmd build
```

빌드 결과는 기존 결과물과 구분된 `dist-demo/`에 생성됩니다. 문서와 실제 구현 기준은 `시연용_개발기준.md`를 확인하세요.
