# TXT 백업·가져오기와 저장 확인 팝업

## 백업 변경

- 새 내보내기: `아이디어-보관함-백업.txt`, UTF-8 BOM 포함, CRLF 줄바꿈. 메모장·텍스트 편집기에서 한국어로 읽을 수 있다.
- 읽기용 본문: 저장 이름, 원래 제목, 분야·직접 입력 주제, 폴더, 저장일, 실제 생성 출처·모델, 세 단어, 조합 조건, 한 줄 소개, 설명, 실행 단계, 단어 연결, 다듬은 내용, 구체화 및 구체화 출처.
- 파일 끝의 `[IDEA-ASSIST-BACKUP-V1 BEGIN]`~`[IDEA-ASSIST-BACKUP-V1 END]` 구간은 복원용 JSON 데이터다. 단순히 JSON 파일의 확장자만 바꾼 것이 아니라, 읽기용 본문을 별도로 제공한다. ID·폴더·수정 버전·출처·줄바꿈 등은 복원 데이터로 보존한다.
- 가져오기는 읽기용 본문이 아닌 **복원 데이터**를 사용한다. 본문을 수정해도 복원 내용은 바뀌지 않으며, 복원 구간을 삭제·손상한 파일이나 임의의 일반 TXT는 오류로 거부한다. 이 제한을 파일 첫 부분에 명시한다.
- 이전 JSON 백업도 지원한다. BOM·LF·CRLF에 대응한다. 앱과 웹의 TXT를 서로 가져올 수 있다.
- 최대 크기: 10,000,000바이트. 기존 제한인 아이디어 500개, 폴더 30개, 사용자 단어 10개는 유지한다. 재귀 파서에 전달하기 전에 JSON 중첩 깊이를 32 이하로 제한한다. 한도를 넘거나 검증에 실패하면 기존 보관함을 쓰기 전에 중단한다.
- 병합은 기존 아이디어/폴더 ID를 우선한다. 새 ID만 추가하고 중복 가져오기는 중복 항목을 만들지 않는다. 기존 작업 초안은 유지하고 백업 안의 초안은 복원하지 않는다.
- 내보내기는 허용된 데이터 필드만 포함한다. API 키, 모델 설정, 비용 동의, 진행 중 초안은 제외한다. 사용자가 아이디어 본문 자체에 비밀정보를 적은 경우까지 자동 삭제하는 기능은 아니므로 백업 공유에 주의한다.
- Android는 시스템 파일 선택기로 `text/plain` TXT를 저장하고 TXT/JSON을 선택해 가져온다. 파일 선택 취소는 아무 것도 저장하거나 가져오지 않는다.

## 저장하지 않고 이동할 때

Apple Design의 일관된 정보 계층·사용자 선택권과 Mobile Native의 작은 화면 스크롤 기준을 따른다.

- Android 기본 AlertDialog 대신 앱의 밝은 회색 둥근 카드, 파란 폴더 아이콘, 공통 32/41 Bold 제목을 사용한다. 웹도 같은 구성이다.
- `저장하러 가기`: 내용을 보존하고 이름·폴더 저장 화면으로 이동한다. 실제 저장 전에는 저장 완료로 표시하지 않는다. 예전의 `저장하고 이어가기`라는 오해 가능한 문구를 바꾼다.
- `저장하지 않고 이동`: 명시적으로 현재 미저장 결과를 버리고 요청한 곳으로 이동한다. 보관함에 이미 저장된 이전 버전은 삭제하지 않는다.
- `계속 다듬기`, X, 뒤로가기/Escape: 팝업만 닫고 현재 아이디어를 유지한다.
- 버튼은 세로로 배치하고 작은 높이·큰 글꼴에서는 카드 내부를 스크롤할 수 있다. 웹 키보드 포커스는 대화상자 안에 유지하고 닫으면 호출 버튼으로 돌아간다.
- 브라우저 탭 닫기/새로고침 경고는 보안상 브라우저가 외형·문구를 제어하므로 커스텀 디자인을 적용하지 않는다. 미저장 결과 또는 진행 중 생성이 있으면 기본 종료 경고를 요청한다. 브라우저 정책·사용자 상호작용 여부에 따라 표시 여부가 달라질 수 있다. 자체 디자인은 **앱 내부 화면 이동** 확인창에 적용된다.

## 검증 결과

- Node 테스트 66개 통과, 웹 빌드 성공.
- Android APK 빌드·에뮬레이터 설치 성공, 코어 계측 검증 16개 그룹 통과. 기존 사용자 보관함의 검증 전후 SHA-256 동일.
- TXT·기존 JSON 복원, 중복 병합, 잘못된 TXT·손상된 복원 구간 거부, 한국어·줄바꿈·따옴표·이모지·구체화 보존, 설정/키 필드 제외를 테스트했다.
- 웹 형식 고정 fixture를 Android에서 가져온 뒤 앱에서 TXT를 내보내고 이를 웹 파서로 다시 읽는 교차 검증에 통과했다. Android 파일 결과 콜백의 실제 파일 쓰기/읽기도 격리된 테스트 보관함으로 통과했다.
- 브라우저에서 실제 `백업` 다운로드 및 동일 TXT의 `가져오기` 후 아이디어 4개가 중복 없이 유지됨을 확인했다. 해당 파일은 로컬 다운로드 폴더에 생성됐으며 Git에 포함하지 않는다.
- 브라우저에서 취소·Escape·저장하지 않고 이동 동작을 확인했다. 320×568에서 모든 버튼이 보이고, 640×360에서는 팝업 내부 스크롤이 가능함을 확인했다. Android 계측 테스트는 취소·X·저장 화면 진입·명시적 버리기를 확인한다.
- 실제 휴대전화 하드웨어는 연결되지 않아 실기기 터치감·제조사별 파일 앱·iOS Safari까지 확인한 것은 아니다. 에뮬레이터와 브라우저 검증을 실기기 검증으로 표현하지 않는다.
