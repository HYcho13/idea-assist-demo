# TXT 내보내기와 저장 확인 팝업

## TXT 내보내기만 제공

- 웹과 Android에서 가져오기 버튼·파일 입력·파일 선택 요청·읽기/복원/병합 코드를 삭제했다. 기존 JSON 백업도 앱으로 가져올 수 없다.
- 보관함에는 TXT 내보내기 버튼만 남긴다. 버튼 아래의 기능 설명 문장도 삭제했다.
- 파일명은 `아이디어-보관함-백업.txt`를 유지한다. UTF-8 BOM과 CRLF 줄바꿈으로 메모장·텍스트 편집기에서 한국어를 읽을 수 있다.
- 제목, 분야·직접 입력 주제, 폴더, 저장일, 생성 출처·모델, 세 단어, 조합 조건, 소개, 설명, 실행 단계, 단어 연결, 다듬은 내용과 구체화를 읽기용 본문으로 제공한다.
- 가져오기가 없어졌으므로 복원용 JSON 구간과 복원 관련 안내도 파일에서 제거했다. 이 파일은 다른 PC에서 읽기 위한 것이며 보관함 자동 복원 수단이 아니다.
- 최대 내보내기 크기는 10MB다. API 키·모델 설정·비용 동의·작업 중 초안은 제외한다. 사용자가 아이디어 본문에 직접 적은 비밀정보까지 자동 삭제하지는 않는다.
- 기존 보관함 파일과 저장된 아이디어는 삭제하거나 초기화하지 않는다. Android 파일 선택 취소는 파일을 쓰지 않는다.

## 저장하지 않고 이동할 때

Apple Design의 일관된 정보 계층·사용자 선택권과 Mobile Native의 작은 화면 스크롤 기준을 따른다.

- Android 기본 AlertDialog 대신 앱의 밝은 회색 둥근 카드, 파란 폴더 아이콘, 공통 32/41 Bold 제목을 사용한다. 웹도 같은 구성이다.
- `저장하러 가기`: 내용을 보존하고 이름·폴더 저장 화면으로 이동한다. 실제 저장 전에는 저장 완료로 표시하지 않는다. 예전의 `저장하고 이어가기`라는 오해 가능한 문구를 바꾼다.
- `저장하지 않고 이동`: 명시적으로 현재 미저장 결과를 버리고 요청한 곳으로 이동한다. 보관함에 이미 저장된 이전 버전은 삭제하지 않는다.
- `계속 다듬기`, X, 뒤로가기/Escape: 팝업만 닫고 현재 아이디어를 유지한다.
- 버튼은 세로로 배치하고 작은 높이·큰 글꼴에서는 카드 내부를 스크롤할 수 있다. 웹 키보드 포커스는 대화상자 안에 유지하고 닫으면 호출 버튼으로 돌아간다.
- 브라우저 탭 닫기/새로고침 경고는 보안상 브라우저가 외형·문구를 제어하므로 커스텀 디자인을 적용하지 않는다. 미저장 결과 또는 진행 중 생성이 있으면 기본 종료 경고를 요청한다. 브라우저 정책·사용자 상호작용 여부에 따라 표시 여부가 달라질 수 있다. 자체 디자인은 **앱 내부 화면 이동** 확인창에 적용된다.


## 검증 기준

- Node: 읽기 가능한 TXT 내용·한글·줄바꿈·따옴표·이모지·구체화 보존, 빈 보관함, 크기 제한, 원본 미변경, 비밀 설정·복원 데이터 제외.
- UI 회귀 검사: 웹·앱에 가져오기 진입점과 버튼 아래 설명이 없고 TXT 내보내기는 유지되는지 확인한다.
- Android 계측 검증: 실제 내보내기 콜백으로 TXT 쓰기, 기존 가져오기 요청 코드가 보관함을 변경하지 않는지 확인한다. 별도 테스트 보관함을 사용한다.
- 저장 확인 팝업과 아이디어 생성·발전·구체화·저장 흐름의 기존 회귀 검증은 유지한다.

실행 결과: Node 테스트 66개, 웹 빌드, Android 빌드·설치, 에뮬레이터 코어 검증 16개 그룹 통과. 사용자 보관함 파일의 검증 전후 SHA-256 동일. 브라우저 보관함에 내보내기만 남고 설명이 없음을 확인했으며, 실제 다운로드한 TXT에서 아이디어 4개의 읽기용 내용과 복원 데이터 미포함을 확인했다.
