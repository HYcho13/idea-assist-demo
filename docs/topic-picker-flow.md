# + 버튼의 주제 선택 팝업

- 적용: React 웹과 Kotlin Android 네이티브 앱. 분야를 무작위로 선택하던 흐름을 제거했다.
- + 버튼은 팝업만 연다. 기존 화면, 단어, 아이디어를 바꾸거나 모델을 호출하지 않는다.
- 첫 화면: 음식 개발, 프로그램 개발, 공모전 주제, 직접 입력의 **선택지 4개**와 취소 버튼.
- 기존 분야 버튼은 선택한 분야에서 세 단어를 뽑고 현재 설정된 생성 방식으로 바로 생성한다.
- 직접 입력 버튼은 같은 팝업 안의 입력 화면으로 전환한다. 주제 1~80자, 공백 입력은 생성 불가. `이 주제로 생성하기`를 눌러야 생성한다.
- `선택지로 돌아가기`로 왕복하는 동안에는 입력을 유지한다. 취소 후 새로 연 팝업의 입력은 초기화한다.
- 취소/닫기는 호출이나 저장 없이 기존 화면으로 돌아간다. 웹 Escape와 포커스 가두기·복귀, Android 시스템 뒤로 닫기도 지원한다.
- 기존 아이디어가 미저장 상태라면 선택 확정 후 기존 저장 확인 절차를 거친다. 단순 팝업 열기·취소에는 이 확인을 띄우지 않는다.
- 생성 중 취소 또는 실패 시 방금 선택한 주제의 단어 조합 화면에서 재시도할 수 있다. 예전 결과 화면이 빈 화면으로 남지 않게 새 생성 문맥을 분리했다.
- 개인정보·API 키 저장 정책, Gemini 요청 수정, 홈에서 분야를 골라 조합하는 흐름은 유지한다. 팝업의 주제는 선택값이며 **단어 조합은 여전히 무작위**다.

검증: Node 자동 테스트, 웹 빌드, Android APK 빌드 및 에뮬레이터 코어 검증. 웹은 직접 입력→선택지 왕복→생성과 취소 후 기존 결과·포커스 유지까지 직접 조작했다. Android는 네 선택지 생성, 공백 차단, 입력 유지와 취소 시 기존 아이디어 보존을 규칙 모드로 검증했다. 실제 휴대폰에서의 키보드·터치감과 실제 개인 키를 이용한 유료 모델 호출은 이 UI 검증에 포함하지 않는다.
